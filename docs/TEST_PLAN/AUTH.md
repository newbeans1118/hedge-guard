## 1. 模块测试要点

| 项 | 内容 |
|----|------|
| 被测模块职责 | 用户/角色/授权、前中后台岗位分离、子账户数据权限（软隔离）（Java + 前端） |
| 本模块 FR 清单 | `FR-AUTH-1` … `FR-AUTH-18`（18 条） |
| 测试重点 | ① **前中后台岗位分离系统级强制**（交易/风控/结算两两互斥；资金岗与交易岗互斥；**不得提供关闭开关**）；② **严禁企业负责人直接操盘**；③ **零落盘**（口令加盐哈希、明文不落盘）；④ **登录失败不区分用户名/口令错误**（防枚举）+ 5 次锁定；⑤ **子账户软隔离安全默认 = 空集**；⑥ 跨子账户查看仅管理层/审计岗且只读 |
| 特殊要求 | 需构造互斥角色组合；需可验证会话超时与锁定 |
| 里程碑 | M1 |

**JUnit 既有覆盖（追溯锚点）**：`java/src/test/java/com/hedgeguard/service/AuthServiceTest.java`（12 个 `@Test`）、`java/src/test/java/com/hedgeguard/service/PasswordHasherTest.java`（5）、`java/src/test/java/com/hedgeguard/dao/SubAccountScopeTest.java`（6）、`java/src/test/java/com/hedgeguard/service/ConfigServiceTest.java`（部分）、`java/src/test/java/com/hedgeguard/web/RequestDispatcherTest.java`（会话）。
