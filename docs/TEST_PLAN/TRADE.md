## 1. 模块测试要点

| 项 | 内容 |
|----|------|
| 被测模块职责 | 按已批准计划下单（期货与期权）、人工确认、绑定计划与子账户、成交回报入链（C++ 下单/事前风控 + Java 落库 + 前端） |
| 本模块 FR 清单 | `FR-TRADE-1` … `FR-TRADE-18`（18 条） |
| 测试重点 | ① **交易必须绑定计划与子账户**（`R-TRADE-1` 正当性红线）；② **人工确认门禁**（无自动交易，确认超时失效）；③ **事前风控全内存、零 DB I/O**（`R-TRADE-3` 架构红线）；④ **回报幂等与事件流不丢不乱序**（`R-TRADE-4`）；⑤ **交易理由结构化必填 + 归属同子账户三层校验**（`Q-13`/`CH-004`）；⑥ **崩溃恢复先重放后服务**（`R-TRADE-13`）；⑦ **行情不驱动决策、过期须标识** |
| 特殊要求 | 需 C++ `ICtGateway` 桩 + Java `InMemoryTradingBridge` 桩（`ARCHITECTURE.md` §8.4，无需 CTP 实盘）；需能观测 CTP 侧报单记录以验证"未发出" |
| 里程碑 | M2（前置门禁：TCP 协议冻结） |

**JUnit 既有覆盖（追溯锚点）**：`java/src/test/java/com/hedgeguard/bridge/TradingBridgeContractTest.java`（8 个 `@Test`，契约面）。
