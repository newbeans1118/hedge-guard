## 1. 模块测试要点

| 项 | 内容 |
|----|------|
| 被测模块职责 | CTP 连接参数、风险阈值、子账户创建与参数、组件间连接、零落盘约束落地（Java + 前端） |
| 本模块 FR 清单 | `FR-CONFIG-1` … `FR-CONFIG-15`（15 条） |
| 测试重点 | ① **零落盘红线**（敏感字段仅内存、启动手工录入）；② **配置分级**（本地 admin 可持久化；API 下发不落盘）；③ **回环绑定**（仅 `127.0.0.1`，配 `0.0.0.0` 拒绝启动）；④ **事前风控参数变更须显式下发 C++ 并确认回执**；⑤ 子账户**不可物理删除仅可停用**；⑥ 配置变更留痕 |
| 特殊要求 | 需可观测配置文件权限/内容；需可验证启动自检 |
| 里程碑 | M1 |

**JUnit 既有覆盖（追溯锚点）**：`java/src/test/java/com/hedgeguard/service/ConfigServiceTest.java`（15 个 `@Test`）、`java/src/test/java/com/hedgeguard/web/SensitiveLoggingAndConfigTest.java`（10）、`java/src/test/java/com/hedgeguard/dao/ConfigAuthSchemaTest.java`（5）。
