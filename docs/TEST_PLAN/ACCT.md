## 1. 模块测试要点

| 项 | 内容 |
|----|------|
| 被测模块职责 | CAS 24 套期关系文档、有效性评估与再平衡、会计凭证草稿、双侧盈亏同时上报（Java + 前端） |
| 本模块 FR 清单 | `FR-ACCT-1` … `FR-ACCT-14`（14 条） |
| 测试重点 | ① **套期关系文档三要素**；② **有效性评估定性三观察点**（品种相关性/方向一致性/期限对应性，`Q-7`）；③ **再平衡四触发**（敞口变动>20% 等，`Q-8`）；④ **凭证借贷平衡**（跨行聚合，服务层校验，`DATA_MODEL.md` §4.4 唯一"约束未下沉"处）；⑤ **凭证草稿含科目建议、不做总账过账**（`Q-9`）；⑥ **双侧盈亏同时上报**；⑦ 子账户标识缺失拒绝生成凭证 |
| 特殊要求 | 需构造不平衡分录；需构造有效性"无效"与再平衡触发场景 |
| 里程碑 | M4 |

**JUnit 既有覆盖**：暂无直接对应（会计为 S4 增量）。
