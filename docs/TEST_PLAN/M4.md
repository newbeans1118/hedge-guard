### 2.1 T-080 复核判例（本套用例设计的强制纪律来源）

以下判例出自 te-verify-t080 / te-verify-t080b 两轮独立复核（`/root/t080-verify.md`、`/root/t080b-verify.md`），**对 M4 全部 ACCT 用例有约束力**：

1. **夹具必须与生产写入同构**：测试夹具若人填 `hedge_plan_id`，会掩盖「生产恒写 NULL」的归集缺陷（TE-T080-001 假绿，TE-T079B-001 同族反向）⇒ **生产形态播种纪律**（§4.2）。
2. **品种级归集语义待裁（O-5）**：层②唯一候选才归集、歧义/未中落残余 ⇒「多计划同品种明细不可细拆」**在裁定前不得判为缺陷**，但须有探针固定当前行为（`TC-M4-02`）。
3. **机读 off-by-one 勘误**：先计数后写账的序列反演（T-080 未决项⑤）——涉及取号/计数类断言须先核引擎语义（`T-196` 已 DONE〔`bb4fd16`〕：谓词取反已订正为删命中行 + 无条件 DELETE 增补；`doDelete` 现位于 `:542`，引用行号随实现漂移、以 grep 实测为准）。
4. **判据不得同源**：断言锚冻结域字面量（如 `new BigDecimal("-8250…")`），**不得引用生产常量**（变异判据纪律，T-189 M2 判例——`feedback_self_same_constant_mutation` 系会话内记忆文件名、仓库不可查，本订正改引仓内可查判例源〔TE-T084 O-6〕）。

## 4. 用例编号与落点约定

### 4.1 编号与唯一预期值

- **编号**：`TC-M4-01` … `TC-M4-30`（M4 专项专用前缀；**不冒用需求模块代号**——ACCT 面细化关系在 §11 映射表中显式列出）。与 `INDEX.md`/`ACCT.md` 既有 `TC-ACCT-*` 落点**互为细化**。
- **唯一预期值**：每条用例**恰好一个决定性期望值**（错误码 / 计数 / 金额 / 布尔），使用 `=`/`==` 而非「约」「合理」等模糊词（禁用词表同 `M3.md` §8）。
- **可复现输入**：凡涉及金额/计数/阈值的用例均给出**具体数值**。

### 4.2 生产形态播种纪律（ACCT 用例设计强制项）

1. **夹具=生产写入同构**：`t_settle_pnl` 夹具行 `hedge_plan_id` **必须按生产形态传 `NULL`**（`SettleService:923` 恒写 NULL）；归集走 `(sub_account_id, product_id)` 层②。任何「人填计划号」的夹具视为假绿隐患，**评审时直接打回**。
2. **生产形态探针必含负证**：每条归集/汇总类用例须含「明细衍生品盈亏非静默 0」负证断言（TE-T080-001 的击杀器形态：`summaryEqualsSumOfDetails`）。
3. **金额自造且判据不同源**：探针金额取夹具专设值（如 −777/−999），**不得与生产常量、种子常量同源**。
4. **事务轨**：涉及多表状态对（凭证↔冲销、关账↔凭证、再平衡↔书面文件版本）的用例**必须用 TransactionAwareInMemory**，并含「失败回滚后原记录不污染」负证（TE-T077-001 判例）。

### 4.3 变异验证要求（执行期门禁）

- 每条**可执行**用例在执行报告（`TEST_RESULT` 对应节）中须附 **≥2 个变异且全杀**（其一建议为判据字段翻转、其二为负证摘除类）；变异须 **clean 重建**（`mvn -B -o clean test`，surefire:test 不重编译主源——既有判例）。
- 断言侧**不得引用生产常量**（同源变异必存活——T-189 M2 判例）。
- 变异后备份 `.orig` + 结束 md5 复位核对（纪律照 `T-080b` §四.1）。

#### TC-M4-01 生产形态播种下汇总 = Σ明细（含残余行）恒等式

- **对应**：`FR-ACCT-5` 验收 4；TE-T080-001 闭环回归守卫。落点：**Java JUnit**（生产形态夹具 + 表行直读探针）。
- **前置**：`t_settle_pnl` 按**生产形态**播种（计划号 NULL）；两个子账户、两个品种的 CLOSE/FLOAT 行；专设金额（如 −8250/−2100，与种子不同源）。
- **步骤**：1) 跑效果评估；2) 直读 `engine.table("hedge_effect").rows`（**不经 service 断言**，SELECT 无 executeQuery——探针口径照 t080b）。

- **变异**：≥2（摘层②归集 / 摘残余行输出——M5/M6 形态，预期 7 红 / 2 红量级）。
