## 1. 模块测试要点

| 项 | 内容 |
|----|------|
| 被测模块职责 | 每日与期货公司核对仓位/资金/成交，子账户独立结算 + **加总对账**（Java + 前端） |
| 本模块 FR 清单 | `FR-SETTLE-1` … `FR-SETTLE-17`（17 条） |
| 测试重点 | ① **Σ 子账户 = 真实账户** 加总对账（`Q-11`）；② **不一致时仅阻断差异所属子账户**、不波及其他、**不阻断平仓**；③ 三方核对差异未闭环不得标记完成；④ **核对任务与电子签署**（`Q-14`：三方各自签署、**不可代签**、**签署后快照变更须重签**、逾期告警进审计报表）；⑤ 阻断生效前 ≤60 s 完成告警（`NFR-REL-6`）；⑥ **差异归属机判取数路径 = `t_agg_diff_candidate` / `t_reconcile_difference`**（`DATA_MODEL.md` §4.4.1，不得解析自由文本） |
| 特殊要求 | 需构造不一致数据并精确定位到子账户；需可枚举候选子账户表 |
| 里程碑 | M2 |

**JUnit 既有覆盖**：暂无直接对应（结算服务为 S4 增量，见 `TASKS.md`）。
