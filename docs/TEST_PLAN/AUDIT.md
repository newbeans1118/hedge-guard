## 1. 模块测试要点

| 项 | 内容 |
|----|------|
| 被测模块职责 | 全链路追溯、违规筛查、季度/年度报表与证据链导出、不可篡改留痕（Java + 前端） |
| 本模块 FR 清单 | `FR-AUDIT-1` … `FR-AUDIT-13`（13 条） |
| 测试重点 | ① **双向追溯** 敞口↔凭证；② **追溯链断点显式标记**（不得静默输出为完整）；③ **在途不计为断点**（两档时窗，`DATA_MODEL.md` §4.4）；④ **违规筛查含"理由缺失/关联缺失"两个并列独立维度**（`CH-004`）；⑤ **审计日志不可篡改**（链式哈希，校验未通过阻断导出）；⑥ **AUDIT 对其它模块只读** |
| 特殊要求 | 需构造被人为移除关联的追溯链；需构造日志篡改以验证校验失败 |
| 里程碑 | M3 |

**JUnit 既有覆盖（追溯锚点）**：`java/src/test/java/com/hedgeguard/dao/AuditFieldsTest.java`（审计字段形状）、`java/src/test/java/com/hedgeguard/web/SensitiveLoggingAndConfigTest.java`（脱敏）。
