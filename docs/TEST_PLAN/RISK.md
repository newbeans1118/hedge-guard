## 1. 模块测试要点

| 项 | 内容 |
|----|------|
| 被测模块职责 | 三级风控（事前 C++ 全内存 / 事中 Java / 事后 Java），承载 6 类风险机制与合规红线 |
| 本模块 FR 清单 | `FR-RISK-1` … `FR-RISK-19`（19 条） |
| 测试重点 | ① **三层限额全序**（层②`SUB_INSTRUMENT` > 层①`SUB_PRODUCT` > 层③`ACCOUNT_PRODUCT`；层③为总账户兜底，不参与"最细命中"选择）；② **并列取一**（同层多条 → 占用率最高者，再并列取 `id` 小者）；③ **价格偏离基准 = 昨结算价**，(2%,5%] 告警+二次确认、>5% 阻断；④ 规模红线商品类 90% / 贸易类 80%；⑤ 期限取较早者；⑥ **只限开仓不限平仓**；⑦ 参数显式下发+回执+顺序保证；⑧ 事前风控全内存零 DB I/O |
| 特殊要求 | **占用率/最细命中的权威在 C++ 内存**——`t_product_quota.used_qty/frozen_qty` DB 投影仅供展示，**必须经协议/内存构造**（`0x0113` `CMD_UPDATE_QUOTA` / `CMD_LOAD_RISK_PARAMS`），**不得用 DB 直插构造**（否则反例误判，见 `DATA_MODEL.md` §4.4 构造纪律 `S-9`） |
| 里程碑 | M3（事前风控随 M2 一并交付） |

**JUnit 既有覆盖（追溯锚点）**：`java/src/test/java/com/hedgeguard/service/impl/ParamDispatchServiceImplTest.java`（15 个 `@Test`，覆盖参数下发/回执/顺序/两阶段）、`java/src/test/java/com/hedgeguard/dao/RiskParamDispatchSchemaTest.java`。
