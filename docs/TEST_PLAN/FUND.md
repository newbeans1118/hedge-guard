## 1. 模块测试要点

| 项 | 内容 |
|----|------|
| 被测模块职责 | 资金流水台账、子账户独立资金、子账户间划拨、出入金（经 CTP）、资金额度控制（C++ CTP 资金接口 + Java + 前端） |
| 本模块 FR 清单 | `FR-FUND-1` … `FR-FUND-17`（17 条） |
| 测试重点 | ① **子账户资金独立且可直接求和**（资金类红线）；② **双人复核硬约束**（发起人 ≠ 审批人，审批人不得交易岗）；③ **子账户划拨后加总不变**（真实账户资金不变量）；④ **出入金经 CTP 异步回执、幂等、超时待查**；⑤ **零落盘**（资金密码仅内存持有）；⑥ 资金额度超限告警 |
| 特殊要求 | 需 CTP 资金接口桩；需可观测 CTP 回执与超时；资金密码须能验证"重启后重新输入" |
| 里程碑 | M2 |

**JUnit 既有覆盖**：暂无直接对应（`FUND` 为 M2 增量）。
