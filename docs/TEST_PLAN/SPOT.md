## 1. 模块测试要点

| 项 | 内容 |
|----|------|
| 被测模块职责 | 管理采购/销售/生产/库存与现货价，并据此计算**实货敞口**（Java + 前端） |
| 本模块 FR 清单 | `FR-SPOT-1` … `FR-SPOT-19`（19 条） |
| 测试重点 | ① **实货敞口是 17 号文"期现一体"的根**（单向结构，`FR-SPOT-16`）；② **敞口三分量（合同未执行量/库存/生产计划）默认全开且快照必存三分量**（`Q-17`，`CH-004`：写侧拒绝、展示侧重算）；③ **现货价口径 A**（`CH-003`：全账户共享、唯一口径=品种+日期+来源、不参与加总）；④ **未映射清单按品类分别留行**（`CH-008`）；⑤ 现货价缺口按用途分拒绝/沿用标注（`Q-12`） |
| 特殊要求 | 需构造三分量与合计不一致的数据；需区分"已映射/未映射"品类；生产计划不进未映射清单 |
| 里程碑 | M1 |

**JUnit 既有覆盖（追溯锚点）**：`java/src/test/java/com/hedgeguard/service/SpotServiceTest.java`（15 个 `@Test`）。
