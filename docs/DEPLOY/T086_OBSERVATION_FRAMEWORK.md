## 4. 告警审计查询口径（观察期内每日执行；SQL 仅为运维查询口径，不进任何代码）

- **Q1 风险告警**：`SELECT COUNT(*) FROM t_risk_alert WHERE alert_time >= ? AND alert_time < ?`（当日 `[00:00, +1d)`）。观察期判据：**违规类（阻断类）累计 == 0**；非阻断提示逐条披露。
- **Q2 事前风控拒绝**：`SELECT COUNT(*) FROM t_trade_pre_trade_reject WHERE reject_time >= ? AND reject_time < ?`。阻断类拒绝 `== 0` 为判据；任何拒绝行均须当日归因。
- **Q3 资金额度告警**：`SELECT COUNT(*) FROM t_fund_quota_alert WHERE alert_time >= ? AND alert_time < ?`。触发即核对占用 vs 资金上限（§1 定值），单列披露。
- **Q4 结算勾稽差异**：`SELECT COUNT(*) FROM t_settle_reconcile_difference WHERE create_time >= ? AND create_time < ? AND resolved = 'N'`。预期 `== 0`。
- **Q5 加总对账**：`SELECT COUNT(*) FROM t_aggregation_check WHERE check_time >= ? AND check_time < ? AND result = 'INCONSISTENT_BLOCKED' AND closed_time IS NULL`。预期新增 `== 0`（既有未闭环行不得带入观察期）。
- **Q6 环境漂移**：`SELECT config_value FROM t_config_item WHERE config_key = 'hg.ctp.env_type'`（每日开市前 + 收市后各一次；恒 `PRODUCTION`）。

> 全部查询以当日参数化执行并留痕（输出快照归档）；**观察期判据锚**：`M4.md` §8.1 `TC-M4-24`
> ——违规告警计数 `== 0`、每日记录连续无缺日、期间结算勾稽差异 `== 0`。
