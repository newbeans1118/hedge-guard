## 事由

`INDEX.md` §2.1「子账户贯穿字段规范（全项目红线）」要求**现货价格记录必须显式携带子账户标识**；
而 `SPOT.md` §2 数据字典要求现货价的**唯一口径 = `品种 + 日期 + 现货价 + 来源标注`**。
两者在数据模型上**直接冲突**：若唯一键含子账户，则同一品种同日可存在多份价格，
"唯一口径"不再成立；若唯一键不含子账户，则现货价行**无法由自身确定归属哪个子账户**，
形式上不满足 §2.1 的"显式携带、不得靠关联推导"。

**注意**：`CH-002` 的 `Q-12` 已确认的是**"现货价缺口的处理策略"**（按用途分拒绝 / 沿用标注），
**并未解决本冲突**。故本问题在 `Q-1`～`Q-17` 全部闭环后**仍然开放**。

## 要求

请产品经理明确以下**三者之一**（并回写 `INDEX.md` §2.1 或 `SPOT.md` §2 正文，注明 `源自变更 CH-003`）：

1. **口径 A（技术负责人倾向前置）**：现货价是**全账户共享的市场数据**，
   `INDEX.md` §2.1 第 1 行的"现货价格记录"**属于措辞过宽**，应从"敞口类必带子账户标识"的清单中**移出**
   （它不参与加总、不是业务归属数据），改为在 §2.1 增加一条脚注说明。
   → 数据模型保持：唯一约束 `(品种, 日期)`，`sub_account_id` 仅记**录入归属**。
2. **口径 B**：现货价**按子账户分别维护**（各业务线可录入自己的价格，互不覆盖）。
   → 数据模型改为：唯一约束 `(子账户, 品种, 日期)`，`is_shared` 语义取消。
3. **口径 C**：**两者并存**（默认全账户共享，允许子账户覆盖）。
   → 数据模型保持双键设计，由配置 `spot.price.scope` 决定生效模式（= 当前架构默认）。

## 产品经理答复（2026-09-20）

**结论：采纳口径 A。现货价是「全账户共享的市场数据（单价）」，不属于「业务归属数据」。**

- 唯一口径 = `品种 + 日期`（+ 现货价 + 来源标注），**唯一键不含子账户**；
  `sub_account_id` 仅记**录入归属**（谁录的），**不是业务归属维度**，也不得作为业务归属使用。
- `INDEX.md` §2.1 第 1 行清单中的「现货价格记录」**移出「敞口类必带子账户标识」清单**，
  改为**脚注**说明（现货价行仍显式携带 `sub_account_id` 以留录入归属，但**不参与业务归属与加总**）。
- **不建议保留**配置 `spot.price.scope` 的 `PER_SUB_ACCOUNT` 分支（理由见下 ②），
  否则一个配置开关即可推翻本口径。

**三点必答**：

**① 是否影响「Σ 子账户 = 真实账户」加总校验 —— 不影响，技术负责人判断成立。**
`INDEX.md` §2.1 配套约束原文限定加总适用对象为「**资金、持仓、结算**三类数据」。
现货价是**单价**（元/吨）而非数量或金额，不属于这三类；对单价做 `Σ` **无业务含义**
（`100 + 200 = 300` 不表示任何东西）。故现货价**不参与加总**，与加总校验零冲突。
（注：`SPOT.md` §2 的「唯一口径」用了「口径」二字，指的是**取值口径唯一**，
不是「唯一键」；两者不构成冲突，但措辞易误读，故在 `CH-003` 中一并澄清。）

**② 是否影响 `Q-12` 缺口处理（沿用最近价 + `price_as_of`） —— 不影响；口径 A 恰是 `Q-12` 成立的前提。**
`Q-12` 的「**沿用最近一期**并标注价格时点」隐含「同一品种存在**唯一一条价格序列**」。
若采口径 B（按子账户各维护一份），则：
- 「最近一期」在子账户之间取值不一致 → 同一品种同日、不同子账户用**不同价格**估值；
- **实货盈亏跨子账户不可比**，`ACCT` 的 `FR-ACCT-5`「汇总 = 明细之和」与 `R-ACCT-12`「口径单一」被破坏；
- 规模红线「**子账户与全账户双算、取严者**」（`Q-1`）失去统一口径；
- `Q-7` 有效性三观察点（**品种相关性 / 方向一致性**）因同一品种价格分裂而失真。

`price_as_of` 是**时间**维度的标注字段，与子账户维度**正交**，本结论不改变其口径。
故口径 A **不削弱** `Q-12`，口径 B **才会**破坏 `Q-12`。

**③ 是否需回写 —— 需回写，走 `CH-003`（L2 澄清性变更，必须由用户拍板；批准前不改 `docs/REQUIREMENTS/`）。**
回写内容（草案见 `dev-team/outbox/CH-003-change.md`）：
- `INDEX.md` §2.1：第 1 行移出「现货价格记录」→ 增脚注（现货价 = 全账户共享市场数据；
  `sub_account_id` = 录入归属；**不参与加总**；唯一口径 = `品种 + 日期 + 来源标注`）；
- `SPOT.md` §2「现货价格」行：唯一口径补注「**不含子账户维度**；`sub_account_id` 仅记录入归属」；
- 建议技术负责人**收敛** `spot.price.scope` 配置（移除 `PER_SUB_ACCOUNT` 分支或标注为不生效）。

**对 M1 的结论**：`DATA_MODEL.md` `TB-SPOT-7` 的**默认实现（`GLOBAL` 模式 + `sub_account_id` 记录入归属）
与本结论完全一致**，故 `Q-ARCH-001` **不阻塞 M1 编码**；`CH-003` 仅解决**需求文档措辞**与**配置项收敛**。
